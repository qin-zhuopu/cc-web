# 05 · 架构与铁律沉淀

实现 12 个 epic 过程中反复强制、固化进代码与测试的所有铁律与关键设计决策。接续者必须遵守这些，否则 import 守卫会拦或对抗评审会抓。

## 六边形核心包铁律（import 守卫强制）

`scripts/check-core-imports.mjs` 扫描 `packages/core/src` 全树，命中即 `npm run test` 失败：
- **禁 import**：`@nestjs/*`、`better-sqlite3`、`@anthropic-ai/*`、`uuid`、`child_process`/`node:child_process`（C2 加的）。
- **禁直调**：`Date.now(`、`randomUUID`（源码文本命中即失败；注释里也别连写这些字面量，会误报——用「系统时钟」等中文描述规避）。
- 守卫已加固：纯函数抽出可测、statSync 容错、空扫描视为失败、行内 `//` 注释剥离后再扫 API 规则。
- **框架只在 apps/api**：唯一带 NestJS 的是 apps/api 的 SharedKernelModule（sk-4），核心包永远零框架。守卫 scanRoot 只限 packages/core，不误伤 apps/api。

## TypeScript 铁律（verbatimModuleSyntax）

`tsconfig.base.json` 启用 `verbatimModuleSyntax`：
- **类型-only import 必须用 `import type`**，值 import 用普通 import。
- **模块说明符必须带 `.js` 扩展名**（NodeNext 解析），否则 `tsc --build` 报错。
- 桶文件 index.ts：类型/接口用 `export type`，枚举/函数/常量值用 `export`。
- 同名冲突处理：C1 与 C2 都有 `TokenUsage`/`TitleGenerationInput`，C2 侧在桶层别名为 `RuntimeTokenUsage`/`RuntimeTitleGenerationInput`。
- strict、ES2022、NodeNext、字段全 `readonly`（不可变领域模型）。

## 术语纪律（CLAUDE.md）

- **禁止用「上下文」指代 bounded context**（歧义）。用全称（Shared Kernel / Conversation / AgentRuntime）或「领域边界」。全程中文注释与沟通。

## 反假数据（AC-9/AC-10，多处强制）

- 可选投影字段**无值 = undefined**，绝不落假 0 / 假空串 / 空对象。
- TokenUsage「只存不算」：无上报字段键根本不存在（用 `...(x!==undefined?{x}:{})` 展开），真实上报的 0 才保留。
- 脏输入降级是**显式行为**（字符串化保留为 text 块），绝不静默丢弃。
- AI 生成空标题也走降级不写脏值；TerminalReason.classified 可选（COMPLETED 不造假 ClassifiedError）。

## C1 · Conversation 关键设计

- **禁 phase**：C1 的 StreamStatus（streaming/completed/interrupted/error）只表达**持久转录行生命周期**，绝不表达实时相位。C1 严禁出现 phase/active/settling/terminal/StreamSession 概念——「现在还在流式吗」由 C2 回答。守卫对 conversation/ 子树扫 phase 标识。这是现有 stop/abort 卡死的根因，在类型层切断。
- **字段归属**：ChatSession 只建模 10 个会话本体字段（id/title/titleOrigin/status/mode/source/workingDirectory/projectName/createdAt/updatedAt），全 readonly。运行时/Provider/Codex 字段（sdkSessionId/runtimeStatus/providerId 等）**严禁进 C1 领域模型**。
- Message 必含 `sessionId`（会话归属 FK）。MessageRole 只有 `user | assistant`（无 system）。
- **C1 不反向依赖 C2、不拼 AI prompt**：TitleGeneratorPort 只 import type，C1 只喂 getPromptView 投影的 recentMessages 纯文本，绝不构造提示词。C1↔C2 环在接线层（NestJS forwardRef）解，核心包只单向 import type。
- **append + touch 同一 now**：append 取一次 Clock.now() 作 createdAt，同一值 touch 会话 updatedAt（AC-7 一致性）。
- **decodeContent 永不抛**：任意脏输入（非 JSON/非数组/畸形 tool_result 的 media/sources）降级为单 text 块，绝不抛。
- **list 过滤权威在用例层**：SessionRepository.listAll() 不传 query、只取全量；过滤/排序/limit 由 ManageSessionService 做（防适配器双重过滤丢 top-N）。
- 时间戳统一 `number`（epoch 毫秒，来自 Clock.now()），架构文档已从 ISO string 对齐为 number。

## C2 · AgentRuntime 关键设计

- **phase 不落库、不与 C1 StreamStatus 混用**（NFR-2/AC-15）：StreamPhase（active/settling/terminal 判别联合）是 C2 实时内存态，绝不落库、C2 类型层不 import C1 StreamStatus。
- **canTransitionPhase 是唯一迁移判据**：合法 active→settling、active→terminal、settling→terminal；非法 terminal→*、*→active。聚合根迁移方法复用它，不重写规则。reconcilePhase 对 running/unknown 返回 null（force-abort 兜底）。
- **#578 中断不卡死（C2 招牌）**：abort 无条件先行——force-abort 安全网独立于外部 interrupt 的 then/finally，interrupt 永挂时 phase 仍同步翻 terminal(aborted)、canAccept()=true。根因是原代码把 abort 排在 interrupt 的 .finally 里，interrupt 挂起则 .finally 永不执行。**注**：聚合根层（c2-2）保证「abort 命令一到 phase 无条件翻终态」；真实 interrupt 永挂的端到端回归在 AbortStreamService（c2-5）编排层。
- **四迁移方法幂等**：markSettling/complete/abort/fail，终态后再调为 no-op（canTransitionPhase 天然拒绝 terminal→*）。
- **buildFinalContent**：五路投影 + 空回合返回 null（FR-2.6 空回合不落库）。snapshot() 必须投影 finalContent（供 c2-4 落库读取）。
- **14 类 AgentStreamEvent**：EventMapper 把外部 Runtime 事件归一为 14 类内部事件；phase_changed 是唯一由 C2 核心产出（不经 mapper、不来自 Runtime）。未知事件降级返回 null（当前联合无 raw 载体），不抛/不伪造/不改语义（AC-8）。
- TerminalReason 6 归因码映射：user_aborted→ABORTED、idle_timeout→TIMEOUT、tool_timeout→PROCESS、process_died→PROCESS（AC-5，ABORTED 不显示成「出错了」）。
