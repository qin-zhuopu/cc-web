# 06 · 架构决策与铁律沉淀

本篇汇总本轮在实现中固化的关键设计决策与守住的铁律，供接续者对齐。

## 本轮新增/固化的关键设计决策

### 1. EventMapper 契约张力：mapMessage vs mapEvent（c2-6）

核心 `EventMapper.mapEvent(raw): AgentStreamEvent | null` 是「1 进 0/1 出」，但一条 SDK assistant 消息可含多个 content block，天然要展开成多个核心事件。
- **决策**：具体 mapper 加 `mapMessage(raw): AgentStreamEvent[]`（适配器主用，展开 0..N），同时 `implements EventMapper` 的 `mapEvent`（委派 mapMessage，恰好 1 个返回它、否则 null）。
- **不改核心契约**：核心 EventMapper 接口保持不动（否则要 correct-course）；扩展只在 apps/api 适配器侧。

### 2. 映射完整消息而非逐字增量（c2-6）

本期 ClaudeSdkEventMapper 映射**完整 assistant 消息**作内容真相源——其 text 天然是全文，契合核心 `text=累积全文` 语义，mapper 无状态、可表驱动测。逐字增量流式（stream_event/SSE 逐 token）留待 EPIC-ACCEPT。

### 3. 流式输入模式（c2-6）

`Query.interrupt()` 仅在流式输入（`prompt: AsyncIterable<SDKUserMessage>`）下可用。适配器用流式输入构造 prompt（yield 一条 user 消息后结束），确保 interrupt 能真正中断在途回合。

### 4. force-abort 调度抽象端口（c2-5）

核心零框架禁直调 setTimeout，但 force-abort 需延时且 AC-4 要可 spy。→ 新增 C2 driven port `ForceAbortScheduler.schedule(fn, delayMs): cancel`，生产用 setTimeout（c2-7）、测试手动 fire。

### 5. TurnRef 由核心以 {streamId} 构造（c2-5/c2-6）

核心不持有/不解释 native 句柄；`interrupt`/`forceKillTurn` 传 `{streamId}`，适配器按 streamId 内部解析实际句柄（Map registry）。

### 6. RuntimeKind 双枚举复用（c2-4 沿用）

`domain/runtime/runtime-kind.ts`（StreamSession 用）与 `ports/runtime-kind.ts`（AgentRuntimePort 用）两处同名 enum，字面量值相同。边界处经 `toRuntimeRunKind` 做值层等价传递，**绝不 as any、不合并、不新增第三处**——属既有技术债，只复用不动。

### 7. TokenUsage 同名别名（c2-6 踩到）

`@codepilot/core` 导出两个 `TokenUsage`：C1 的（字段可选）+ agent-runtime 的（inputTokens/outputTokens 必填）。桶文件用别名 `RuntimeTokenUsage` 导出后者。**跨边界引用 agent-runtime 的 token 类型必须 import `RuntimeTokenUsage`**，否则解析到 C1 那个致类型不兼容。

### 8. 单 active 无 await 原子段（c2-4 评审修复）

`start()` 里把 provider `resolve()`（唯一 await）提到单 active 检查之前，使「查旧 active → abort → delete → new → register」成为无 await 同步段，杜绝并发 start 交错破坏 AC-11（TOCTOU）。

## 守住的铁律（贯穿全程）

1. **核心包零框架**：`packages/core` 禁 import `@anthropic-ai/*`/`@nestjs/*`/`better-sqlite3`/`child_process`/`codex`/`node:timers`；禁直调 `Date.now`/`new Date`/`randomUUID`/`setTimeout`。SDK/框架全在 apps/api，守卫 `check-core-imports` 只扫 packages/core 且始终 0 命中。
2. **import type + .js**：verbatimModuleSyntax 下类型-only import 用 `import type` + `.js` 说明符（NodeNext），apps/api 侧同守。
3. **反假数据（AC-9）**：tokenUsage 无 Runtime 上报则字段省略、绝不填 0；availability 探测不了标 unavailable/unknown、不显假 ready。
4. **归因经 ErrorClassifier**：中断/超时归因一律经 `SK.ErrorClassifier.classify`（构造相应语义的错误），绝不手拼 ClassifiedError 造假 code。
5. **复用不重写**：StreamSession 迁移方法/reconcilePhase/canTransitionPhase/buildFinalContent/terminal-reason 全复用，绝不在用例/适配器重写迁移或归类规则。
6. **phase 不落库、registry 非持久层**：实时内存态，不 import C1 持久 StreamStatus 做实时判断。
7. **落 C1 只经用例**：回合产物只经 C1.AppendMessageUseCase.append 写，不直写库/不持有 Repository。
8. **术语纪律**：不用「上下文」指代 bounded context；用全称（Shared Kernel/Conversation/AgentRuntime）或「领域边界」。
9. **每 epic 一个干净断点**：精准暂存本 epic 产物，不混入用户的文档/配置/package-lock 无关改动。
10. **token 绝不入库/回显/写日志**：`.env` gitignored，适配器注入 options.env 时不回显、availability 报缺配置只报 key 名不报值。

## 环境坑（Git-Bash 特有）

- 裸 `git`/`find` 输出异常 → 用 `/mingw64/bin/git` 全路径或 Glob。
- `timeout` 撞 Windows `timeout.exe`（语法不兼容）→ 别用，靠脚本自然收尾或 SDK 自身超时。
- 项目是独立 git 仓库（`codepilot-web/` 自身即根），勿混入上层 dotfiles。
